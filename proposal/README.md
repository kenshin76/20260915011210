# 웹 제안서 — 모바일 상품권 판매 사이트 보안 강화·개편 (위시켓 158459)

제안서 원문 `../제안서.md` 의 **요약 웹 버전**입니다. 정적 파일 3개로만 구성되어 있으며 빌드 과정이 없습니다.

```
proposal/
├── index.html        단일 페이지 (내용 전부가 HTML에 있음 — JS가 꺼져도 읽힙니다)
├── assets/
│   ├── style.css     토큰 → 기본 → 레이아웃 → 컴포넌트 → 섹션 → 모션 → 반응형 → 인쇄
│   └── app.js        의존성 없음. IIFE + 'use strict'
├── .nojekyll         GitHub Pages에서 Jekyll 처리 건너뛰기
└── README.md         이 파일
```

## 공개 범위 경고

> **GitHub Pages는 저장소가 Private이어도 무료 플랜에서 페이지가 공개됩니다.**
> 이 페이지에는 **적용 단가(250,000원/MD)와 역할별 투입 MD**가 들어 있습니다.
> 주소를 아는 사람은 누구나 열람할 수 있으므로, 고객사 전달용 링크 외에 공개 위치에 노출되지 않도록 주의하십시오.
> 검색 노출은 `<meta name="robots" content="noindex, nofollow">` 로 막아 두었습니다.

`제안서.md`, `요구사항.md`, `design/` 등 대외비·내부 자료는 이 폴더에 두지 마십시오. 저장소 루트의 `.gitignore` 로 제외되어 있습니다.

## 배포

저장소 루트가 웹 루트가 되므로 이 폴더는 `.../proposal/` 하위 경로로 서비스됩니다.

```
https://<user>.github.io/<repo>/proposal/
```

모든 자산 경로가 상대 경로(`assets/style.css`)이므로 저장소 이름이나 하위 경로가 바뀌어도 그대로 동작합니다.

배포 후 내용이 예전 것으로 보이면 **브라우저 캐시**입니다. GitHub Pages는 HTML에 `max-age=600`을 붙입니다 — 강제 새로고침(⌘⇧R / Ctrl+F5)하거나 `?v=2`를 붙여 확인하십시오.

## 수정 가이드

- **수치를 고칠 때는 반드시 `제안서.md`를 먼저 고치고** 그 값을 여기로 옮깁니다. 원문과 웹이 어긋나면 심사에서 신뢰가 무너집니다.
- 색·서체·간격은 `assets/style.css` 상단의 **의미 토큰**(`--key`, `--body`, `--hair` …)만 바꿉니다. 원색 팔레트(`--red-700` 등)는 고정값입니다.
- 화면 모드는 **시스템 → 라이트 → 다크** 3상태이며 `localStorage`에 저장됩니다.
- 인쇄 시 탭·아코디언이 자동으로 펼쳐지고 애니메이션이 확정 상태로 고정됩니다(상단 바 「인쇄」 버튼 또는 브라우저 인쇄 메뉴 모두 대응).

## 점검 항목

- 데스크톱 라이트 / 데스크톱 다크 / 태블릿 / 모바일에서 JS 오류 0건
- 4종 모두 가로 오버플로 0건 (`documentElement.scrollWidth === clientWidth`)
- 전체 스크롤 후 미발동 리빌 0개, 카운터 전부 최종값, 막대 전부 목표 폭
- `prefers-reduced-motion`에서 내용이 모두 보이는가
- 인쇄 미리보기에서 접힌 내용이 펼쳐지고 다크로 나가지 않는가
